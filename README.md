# M-Pesa Python Simulation (Version 1.0)

This is a simple money-sending program built entirely in Python using basic concepts like variables, functions, and conditional statements (if/elif/else). 

## Features
- Validates user input and checks account balances before executing transactions.
- It also Generates a simulated unique transaction confirmation code.
- Calculates and displays the remaining user balance after a successful transfer.

## Why I Built This
I created this project during my first year of university to practice self-learning Python. It replicates the core transaction logic of the real-world M-Pesa mobile money system using functional code without relying on loops or external databases.
